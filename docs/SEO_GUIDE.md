## Cần làm thêm:

### 1. Google Search Console
1. Truy cập: https://search.google.com/search-console
2. Thêm property với URL: `https://webpod.org`
3. Xác minh ownership:
   - Option 1: Thêm HTML file verification (tạo file trong /public)
   - Option 2: Thêm meta tag vào <head>
   - Option 3: DNS record
4. Submit sitemap: `https://webpod.org/sitemap.xml`

### 2. Google Analytics & Tag Manager
Uncomment và thêm IDs vào file index.html:
- Google Analytics 4: Thay `G-XXXXXXXXXX` bằng measurement ID
- Google Tag Manager: Thay `GTM-XXXXXXX` bằng container ID

### 3. Tạo Social Media Images
Tạo file `og-image.jpg` (1200x630px) và đặt vào folder `/public`:
- Nên có logo POD
- Text: "POD - Pay On Delight"
- Subtitle: "Demo miễn phí - Trả phí khi hài lòng"

### 4. Bing Webmaster Tools
1. Truy cập: https://www.bing.com/webmasters
2. Thêm site và verify
3. Submit sitemap

### 5. Local SEO (Google Business Profile)
Nếu có địa chỉ văn phòng:
1. Tạo Google Business Profile
2. Thêm địa chỉ, số điện thoại, giờ làm việc
3. Thêm ảnh văn phòng

### 6. Content Marketing
- Tạo blog với các bài viết về:
  - Web development best practices

  - Tutorials về Next.js, Nest.js
