| CLS (Cumulative Layout Shift) | ~0.1 | <0.1 | ✅ Set explicit image dimensions |

### 13.1 Potential Risks

**Risk 1: Google Algorithm Updates**
- Probability: High (2-3 major updates/năm)
- Impact: Medium-High
- Mitigation: Focus on quality content, user experience, avoid black-hat

**Risk 2: Negative SEO (Competitors)**
- Probability: Low-Medium
- Impact: Medium
- Mitigation: Monitor backlinks, disavow toxic links, strong content

**Risk 3: Low Conversion Rate**
- Probability: Medium
- Impact: High
- Mitigation: A/B testing, UX optimization, better targeting

**Risk 4: Budget Constraints**
- Probability: Medium
- Impact: Medium
- Mitigation: Start with Option A (free), scale when profitable

**Risk 5: Content Quality Issues**
- Probability: Medium (if outsourced)
- Impact: High
- Mitigation: Editorial guidelines, review process, self-write important content

### 13.2 Contingency Plans

**If rankings drop:**
1. Audit technical SEO
2. Check Search Console for issues
3. Review recent algorithm updates
4. Analyze competitors
5. Update content

**If traffic doesn't convert:**
1. Analyze user behavior (heatmaps)
2. A/B test CTAs
3. Improve demo process
4. Add social proof
5. Retarget visitors

**If budget runs out:**
1. Pause paid efforts
2. Focus on organic content
3. Leverage community (Viblo, GitHub)
