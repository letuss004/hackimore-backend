📝 Hướng dẫn sử dụng Facebook Debugger:

  1. Click vào nút "Facebook Debugger" ở trên
  2. Nhập URL: https://webpod.org/
  3. Click "Debug" để kiểm tra
  4. Nếu cache cũ, click "Scrape Again" để làm mới
  5. Kiểm tra "Scraped URL" section để xem preview

ℹ️ Important Notes

  • Facebook cache: Facebook lưu cache Open Graph data. Sử dụng Debugger để xóa cache.
  • HTTPS required: Facebook yêu cầu HTTPS cho images.
  • Image size: Tối thiểu 200x200px, khuyến nghị 1200x630px.
  • Image format: Hỗ trợ JPG, PNG. Tránh SVG.
  • File size: Nên < 8MB để tải nhanh.
  • Absolute URLs: Luôn dùng full URL (https://webpod.org/...) thay vì relative path.
